# Recovered data

Selected `objects.xml`/`grounds.xml` and map assets remain third-party material; the backend license does not relicense them. `sfx/music/sorc.mp3` is the selected client's requested track, recovered unchanged from moistosaurus/realm-src `1855c017eab870d13f0b61b1cf0b9e66a01922ff`, `common/resources/web/music/sorc.mp3` (see `REALM-SRC-LICENSE`); The four legacy weapon clips in `sfx/` are unchanged files from that pin's `common/resources/web/sfx/`. No separate audio-rights grant is claimed.

**Map candidates, not authenticated official 123.5.1 layouts:**
- Tutorial, Nexus, Limbo and Vault: trapped/rotmg_svr at `593e490803fe0ad168ead408cacd5287d778acfe`. The old 96×96 shore crop remains a reference. Live Realms select a prepared 2048×2048 layout from `realm-catalog.json` per creation; see `FSOD-NOTICE` and `realms/NOTICE`. The procedural island is now only a unit-test fixture.
- Guild Halls 1-4: used cells from moistosaurus/realm-src `1855c017eab870d13f0b61b1cf0b9e66a01922ff`, `common/resources/worlds/GuildHall0..3.wmap`; losslessly converted to the existing format on 16 October 2026 (all source heights are zero). See `REALM-SRC-LICENSE`.
- Oryx Castle: used-cell geometry and roster from Bledixon/Project-B-Public `9947199c8d384cc8220657bfa7519dc92e47adb9`, `server-source/wServer/realm/worlds/OryxCastle.jm` (AGPL; see root `LICENSE`). Required Project-B credits: Bledixon, Kithio, Travoos, Lunarshade, Club559, Skilly, BLOODQWEEN, Miniguy, Arcanuo, Jade, ossimc82 and everyone who helped make the project. The newer alloy Castle was rejected because it contains unsupported Janus/custom markers.
- Oryx Chamber and Wine Cellar: used-cell geometry and rosters from Zolmex/alloy-server at `c4bd1169a1593fd775b59d25a40edfa1cbd475c4`, `OryxChamber.jm` / `WineCellar.jm`; see `ALLOY-LICENSE`. JSON absent grounds retain the author's void default `0xff`; ambiguous Castle `Grey Circle` is explicitly selected as `0x61`. These are candidate layouts, not authenticated official maps.
- Cave: lossless `Common/Resources/World/Data/PirateCave.jm` conversion from Zolmex/alloy-server at `c4bd1169a1593fd775b59d25a40edfa1cbd475c4`; full geometry, roster and connected-wall configurations retained. Original ancestry is unverified; see `ALLOY-LICENSE`.
- Sprite World/Undead Lair: the same Alloy commit's `SpriteWorld.jm`/`UndeadLair3.jm`; used geometry, objects and configurations retained. Undead Lair's ambiguous `Grey Circle` name explicitly uses selected type `0x61`, not `0x65`.
- Snake Pit: seeded reconstruction using selected brown walls, snake grates and seven connected rooms, including destructible boss cover. It is not a recovered official generator; the Alloy candidate's unsupported invisible spawner is not silently substituted.

HP/projectiles use selected XML. AI/loot derive from trapped's Shore/Cave/Lowland/Midland/Highland/Mountain/SnakePit/Undead_Lair behavior tables and moistosaurus/realm-src's SpriteWorld/UndeadLair candidates at `1855c017eab870d13f0b61b1cf0b9e66a01922ff` (GPL-3.0, `REALM-SRC-LICENSE`). XP, credit thresholds, respawn, drop rates and lifetimes remain provisional server policies, not established historical fidelity. The bounded shore encounters stay near coastal arrival; inland allocation adds at most 32 enemies per present XML biome. Native checks are partial: prepared-character Stheno/Oryx victories and a normally rolled Incantation pickup are verified, but a complete earned multiplayer journey through the implemented Realm finale is not. Realm portal rolls are explicit provisional candidate rules: Medusa→Snake17%, Sprite God's bounded Sprite Children→Glowing11%, Ghost God→Lair17% (Cubes→Cave retain1%). Boss shields/summons,20-second Limon corner boxes, delayed grenades, single-use traps and slime splits are bounded server actors; they are not authenticated official AI. Limon's candidate self-looping shield state is reconstructed as1.5-second vulnerable/3.5-second shielded windows. Earned base fame is XP/1000, a reference-server policy rather than verified 123.5.1 scoring; historical death bonuses are not restored. Account-private loot and Vault access are enforced server-side.
